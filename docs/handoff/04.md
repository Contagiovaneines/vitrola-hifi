# Handoff 04 — Agente Design / Frontend

## 1. Objetivo da Etapa
Criar a base completa do projeto frontend com Vite + React + TypeScript + Tailwind CSS, implementando o sistema de rotas (Início, Biblioteca, Playlists, Fontes, Aparência), adaptando fielmente as 4 telas do Stitch para janelas Windows desktop widescreen (1366×768 e 1920×1080), modularizando os componentes táteis, garantindo animações físicas acopladas exclusivamente ao estado de reprodução (`playing`) e compilando sem erros TypeScript.

## 3. Decisões Principais
1. **Acoplamento Físico Estrito das Animações:** O disco de vinil e o LED da agulha fonocaptora animam unicamente quando o estado é `playing`. Em pausa, o braço sobe através da alavanca de cue (12°) e a agulha apaga; no estado vazio, o braço repousa no suporte (0°) e exibe o feltro antiestático da vitrola.
2. **Layout Horizontal Proporcional:** As interfaces altas do Stitch foram harmonizadas em um layout de duas colunas (console esquerdo para toca-discos e transporte, console direito para instrumentação analógica), garantindo visualização sem rolagem vertical em telas 1366×768 e 1920×1080.
3. **Nenhum Script Externo de CDN:** Eliminadas chamadas a scripts externos em tempo de execução; estilos compilados via Tailwind e ícones empacotados localmente via `lucide-react`.
