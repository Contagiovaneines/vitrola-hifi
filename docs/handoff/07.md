# Handoff 07 — Agente Viabilidade Deezer e YouTube

## 1. Objetivo da Etapa
Executar a avaliação de viabilidade técnica e conformidade legal das integrações com **Deezer** e **YouTube**, sem o uso de scraping ou endpoints privados não documentados:
- Determinar o acesso vigente no Deezer para busca, metadados, prévias de 30 segundos, limitações de planos e restrições de novos registros de desenvolvedor.
- Separar o YouTube Data API e o YouTube IFrame Player API da ausência de API pública do YouTube Music.
- Incorporar player oficial do YouTube com vídeo visível, dimensões adequadas e controles exigidos, sem extração de áudio, download ou reprodução oculta em segundo plano.
- Produzir a matriz comparativa completa em `docs/07-matriz-provedores.md`.
- Conduzir testes automatizados de ponta a ponta para que nenhuma integração seja classificada como funcional sem validação real.

## 2. Arquivos Alterados / Criados
- `src/services/providers/deezer/DeezerPlaybackProvider.ts`: Provedor oficial com busca pública via JSONP (compatibilidade universal sem CORS bloqueado), reprodução de prévias MP3 de 30s integradas ao Web Audio API (`AudioEngine`) para movimentação real dos medidores VU analógicos.
- `src/services/providers/youtube/YouTubePlaybackProvider.ts`: Adaptador de controle do YouTube IFrame Player API oficial com gerenciamento de estado, volume e seek.
- `src/components/player/YouTubePlayerMonitor.tsx`: Componente de monitor CRT retrô para exibição obrigatória do vídeo oficial incorporado na tela, com input de URL/ID e badge de conformidade.
- `src/views/SourcesView.tsx`: Tela de fontes aprimorada com busca interativa no catálogo Deezer, botão para tocar a prévia de 30s diretamente no prato da Vitrola, link oficial para faixa completa e monitor de reprodução de vídeo do YouTube embutido.
- `src/views/PlayerView.tsx`: Inclusão do monitor de vídeo do YouTube quando a fonte YouTube estiver selecionada.
- `src/App.tsx`: Conexão do manipulador `handleSelectTrack` à aba de fontes para reprodução direta das prévias pesquisadas no Deezer.
- `scripts/test_providers_deezer_youtube.js`: Script de teste end-to-end de consulta à API do Deezer, verificação do CDN de áudio MP3, extração de IDs de URL do YouTube e endpoint oficial `oEmbed`.
- `docs/07-matriz-provedores.md`: Matriz com auditoria detalhada de cada ação por provedor (Local, Spotify, Deezer, YouTube e YouTube Music).

## 3. Decisões Principais
1. **Conformidade Ética e Legal Irrestrita:**
   - **Deezer:** O Vitrola não simula reprodução completa de faixas fechadas nem cria botões falsos de login. A capacidade de busca e prévia oficial de 30s é 100% funcional. Para faixas completas, fornece o link oficial para abertura no Deezer.
   - **YouTube:** Cumprimento rigoroso das seções III.A.1 e III.E dos Termos de Serviço da API. Nenhuma extração de áudio foi implementada; o vídeo é mantido obrigatoriamente visível durante a reprodução.
   - **YouTube Music:** Declarado com transparência como indisponível para áudio isolado de terceiros.
2. **Áudio Deezer com Balística Real:**
   - As prévias MP3 do CDN do Deezer (`https://cdnt-preview.dzcdn.net/...`) fornecem cabeçalho `Access-Control-Allow-Origin: *`, permitindo conexão direta com o grafo Web Audio API do Vitrola e alimentando a deflexão dos medidores VU em tempo real.
