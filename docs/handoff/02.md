# Handoff 02 — Agente Arquiteto

## 1. Objetivo da Etapa
Definir a arquitetura completa de software para o aplicativo Windows local-first "Vitrola", especificando o grafo de processamento de sinal, os contratos de dados e interfaces TypeScript (`Track`, `Album`, `Playlist`, `ProviderCapabilities`, `PlaybackProvider`), o fluxo de eventos de reprodução, a fronteira nativa, a persistência de biblioteca com SQLite/IndexedDB, as estratégias de medição real de PCM para os medidores VU, e o plano de fases priorizando o MVP A–C.

## 2. Arquivos Alterados / Criados
- `docs/02-arquitetura.md`: Especificação arquitetural integral de módulos, interfaces TypeScript, persistência, cache de capas, grafo Web Audio e conformidade de streaming.
- `docs/handoff/02.md`: Este relatório de passagem de estágio.

## 3. Decisões Principais
1. **Medição PCM Real para Medidores VU:** As agulhas dos medidores analógicos não utilizarão jitter aleatório. Utilizarão `AnalyserNode` do Web Audio API com cálculo RMS legítimo e conversão logarítmica para dBFS com balística de 300ms de subida e 600ms de inércia. Sem sinal ou em pausa, as agulhas repousam no valor mínimo.
2. **Matriz de Capacidades Explícita (`ProviderCapabilities`):** Cada fonte declara o que suporta. Controles indisponíveis para fontes externas (como pitch/RPM em streams remotos ou duração desconhecida) serão visualmente desabilitados com justificativa.
3. **Persistência Local-First:** Indexação baseada em banco de dados local com hash e timestamp para detecção de arquivos movidos ou renomeados sem perda de metadados ou playlists.
4. **Integração com Windows SMTC:** Implementação nativa via `MediaSession API` para resposta ao teclado e painel de mídia do Windows 10/11.

## 4. Comandos, Testes e Resultados
- Validação conceitual dos formatos de áudio nativos do Chromium/WebView2: MP3, FLAC, WAV, OGG, AAC/M4A.
- Validação das interfaces de dados e fluxo sequencial de eventos.
- Mapeamento das dependências nativas para a fase de execução.

## 5. Riscos Identificados
- **Ambiente de compilação C++ no host Windows:** A máquina atual possui Node LTS (v24.21.0), mas não possui o MSVC C++ Build Tools instalado para compilação Rust direta. O plano de execução e o empacotamento devem prever uma estrutura híbrida (Tauri quando as ferramentas nativas estiverem disponíveis / Shell executável desktop via empacotamento webview/electron/portable) para garantir entrega 100% funcional do app Windows.
