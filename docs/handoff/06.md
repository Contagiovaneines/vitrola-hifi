# Handoff 06 — Agente Spotify

## 1. Objetivo da Etapa
Implementar a integração oficial com a plataforma Spotify com base nas regras de conformidade e segurança da API:
- Fluxo de autorização OAuth 2.0 Authorization Code com PKCE (sem segredos no cliente nem requisição de senha dentro do aplicativo).
- Tratamento explícito da exigência de conta Spotify Premium para streaming direto via Web Playback SDK.
- Modo alternativo de controle remoto Spotify Connect para reprodução em dispositivos autorizados.
- Tratamento de códigos de erro HTTP (401 token expirado, 403 sem Premium, 404 sem dispositivo ativo, 429 rate limit).
- Proibição de equalização, alteração de áudio ou cacheamento do catálogo do Spotify.
- Guia passo a passo de registro em `docs/06-spotify-config.md`.

## 2. Arquivos Alterados / Criados
- `src/services/providers/spotify/SpotifyAuth.ts`: Módulo com geração criptográfica segura de `code_verifier` e `code_challenge` (S256), troca de authorization code, renovação automática com `refresh_token` e desconexão.
- `src/services/providers/spotify/SpotifyPlaybackProvider.ts`: Adaptador de reprodução implementando `PlaybackProvider`, gerenciamento de chamadas `play`, `pause`, `seek`, `setVolume`, com mensagens claras para falta de conta Premium e ausência de dispositivo ativo.
- `src/views/SourcesView.tsx`: Interface interativa de configuração do Spotify com inserção de Client ID, status de conexão (Conectado / Condicionada) e botão de desconexão.
- `docs/06-spotify-config.md`: Documentação técnica completa instruindo o usuário sobre como criar a aplicação no Spotify Developer Dashboard e configurar as Redirect URIs.

## 3. Decisões Principais
1. **Segurança Rigorosa:** Nenhum Client Secret é armazenado no código ou exposto. O fluxo PKCE garante segurança em clientes públicos como navegadores e webviews.
2. **Postura de Integridade (Não Declarar Streaming Concluído sem Credenciais):** Como credenciais de teste ao vivo do Spotify exigem que o usuário registre sua própria chave de desenvolvedor (o que o agente não deve forjar nem solicitar senhas pessoais), a interface entrega o adaptador, a tela de configuração e a máquina de estados completa. O streaming ao vivo fica documentado como condicionado à configuração do Client ID e à presença de conta Premium.
3. **Respeito aos Termos do Spotify:** O stream do Spotify é protegido por DRM e não é roteado através dos nós de equalização ou gravadores do Web Audio API.

## 4. Comandos, Testes e Resultados
- Compilação via `npm run build`: Sucesso em 2.24s, 0 erros TypeScript.
- Verificação do fluxo de geração de code challenge SHA-256 e tratamento de expiração de token.

## 5. Pendências
- Para audição ao vivo de faixas do catálogo Spotify, o usuário precisará cadastrar seu Client ID seguindo as etapas em `docs/06-spotify-config.md` e possuir assinatura Spotify Premium ativa.
